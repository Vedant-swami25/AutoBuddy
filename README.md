🚀 Installation

Clone the repository

```bash
git clone https://github.com/Vedant-swami25/AutoBuddy.git
```

Install dependencies

```bash
npm install
```

Create `.env`

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```

Import demo data

```bash
npm run migrate
```

Run project

```bash
npm start
```
